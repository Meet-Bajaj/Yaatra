The Problem

Urban Indian commuters face a painful trade-off every day

💰 Ride-Hailing is Expensive

₹300–500/day for solo cab rides makes daily commuting unaffordable for students and professionals

😤 Existing Carpool Apps are Unreliable

No real-time matching, messy WhatsApp groups, no verification or safety features

🪑 Empty Seats Going to Waste

Millions of car owners drive alone daily with 3–4 empty seats — no platform to monetize them

Driver Features

🚗 Carpool Driver

Set home/work addresses, departure time, days of week, available seats (max 3), price per seat, women-only preference. Publish ride and manage incoming rider requests.

📶 Go Online

Professional drivers toggle online status to receive pooled ride requests along their current corridor. Real-time location pushed to Redis driver pool for matching.

💰 Earnings Dashboard

Daily earnings summary, pending settlements, wallet balance, withdrawal to bank. Commission auto-deducted (10–15% carpool, 20–25% professional).

📋 Request Management

View incoming rider requests for scheduled rides. Accept/reject with reason. For pro drivers: pooled queue with ≤2 pickups per trip.

🚗 Vehicle Management

Add multiple vehicles with make, model, color, license plate, capacity. Upload fitness certificate and commercial permit for verification.

📊 Ride History

Complete trip log with fare breakdown, rider ratings, and route replay. Export for tax purposes.

Matching Algorithm

On-Demand Matching

// Corridor-based matching with PostGIS SELECT * FROM driver_pool WHERE ST_DWithin( driver_corridor, ST_MakeLine(pickup, dropoff), 5000 -- 5km max detour ) AND is_online = true ORDER BY detour_time ASC, rating DESC LIMIT 10;

Target: < 2s response time using Redis-cached driver locations

Scheduled Matching

// Route overlap for recurring rides SELECT * FROM recurring_rides WHERE ST_DWithin( route, -- PostGIS LINESTRING ST_MakePoint(pickup_lng, pickup_lat), 3000 -- 3km radius ) AND schedule->>'days' CONTAINS 'MONDAY' AND departure_time BETWEEN '08:00' AND '09:30';

Scoring: proximity + rating + women-only preference + seat availability

Safety & Trust

🚨

Emergency SOS

One-tap emergency button triggers alerts to emergency contacts via SMS + push notification. Records audio/video. Alerts Yaatra safety team.

🪪

Aadhaar KYC

Document upload (Aadhaar, DL, PAN) via MinIO S3. Manual review queue for admins. Verification badges on profiles.

📍

Trip Sharing

Share live trip status with trusted contacts via masked link. Real-time location updates every 30 seconds.

👩

Women-Only Mode

Female riders can filter for women-only carpool rides. Driver and all co-riders must be verified female.

⭐

Ratings & Reviews

Post-ride rating (1–5) with tags (punctual, safe, comfortable). Aggregate score on driver profiles. Report safety issues.

🔒

Data Security

TLS 1.2+ encryption, phone number masking, OTP rate limiting, PCI DSS compliance via Razorpay tokenization.

API Design

RESTful + WebSocket — 50+ endpoints with Swagger documentation

// Auth (OTP-based) POST /auth/otp → Send OTP POST /auth/verify → Verify → JWT // Rides GET /rides/available → Search rides POST /rides/book → Book ride POST /rides/:id/cancel → Cancel + penalty // Driver POST /driver/offer → Publish commute POST /driver/go-online → Join Redis pool POST /driver/accept → Accept request // Payments POST /payments/charge → Razorpay AUTH POST /payments/payout → Driver payout // WebSocket Events ride.match · trip.assigned · trip.location trip.completed · notification.new

🔐 Authentication

JWT tokens with phone + role in payload. OTP via Twilio/msg91 with Redis TTL + rate limiting.

🛡️ Authorization

Role-based guards: @Roles('ADMIN'), @Roles('DRIVER'). Custom decorators: @CurrentUser().

📐 Validation

class-validator DTOs with whitelist + transform. Swagger auto-documentation at /api/docs.

📡 Real-Time

Socket.IO gateway with JWT handshake. Room-based: user:{id} and trip:{id} rooms.
