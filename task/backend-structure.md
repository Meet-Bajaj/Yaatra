# Yaatra Backend — Directory & File Structure

> Target structure for the full MVP build. `[EXISTS]` = already initialized in `backend/`. Everything else = to create.
> Conventions: one NestJS module per feature under `src/modules/`, each with `controller`, `service`, `dto/`, `entities/`. Shared infra lives in `src/common/` and `src/prisma/`.

## File Naming Conventions (follow exactly)
| File type | Pattern | Example |
|-----------|---------|---------|
| Module | `*.module.ts` | `ride.module.ts` |
| Controller | `*.controller.ts` | `ride.controller.ts` |
| Service | `*.service.ts` | `ride.service.ts` |
| Gateway | `*.gateway.ts` | `location.gateway.ts` |
| DTO | `dto/*.dto.ts` | `dto/book-ride.dto.ts` |
| Entity | `entities/*.entity.ts` | `entities/ride-option.entity.ts` |
| Strategy | `*.strategy.ts` | `jwt.strategy.ts` |
| Guard | `guards/*.guard.ts` | `guards/roles.guard.ts` |
| Decorator | `decorators/*.decorator.ts` | `decorators/roles.decorator.ts` |
